# 恋ログ 💌

マッチングアプリで出会った人を、あなたのスマホの中だけでこっそり管理するアプリ。

## 特徴

- **完全プライベート** — データは端末内(localStorage)にのみ保存。サーバーには一切送信されません
- **進展ステータス管理** — マッチ中 → メッセージ中 → デート済み → 交際中 / 終了
- **タイムライン** — 会った日・話した内容を記録して「この話もうしたっけ?」を防止
- **相性メモと好感度★** — 合うところ・気になるところを整理
- **AIイラストのアバター** — 実写不要。Gemini生成のイラスト16種から選択
- **PWA対応** — ホーム画面に追加すればアプリのように使え、オフラインでも動作

## デザイン「思い出スクラップ帳」

出会いの思い出をマスキングテープで貼っていく、明るい紙のアルバムがコンセプト。
明るい紙(#fffcf6)に苺紅・蜂蜜・ミント・空色。見出しはKaisei Decol、本文はZen Kaku Gothic New。

- カードの角に貼られた「マステ」の色=進展状況(空色=マッチ中、ミント=メッセージ中、蜂蜜=デート済み、苺紅=交際中)
- 詳細画面の進展は「章スタンプ」。進んだ章にスタンプが押され、現在の章は苺紅の押したてスタンプ

## 使い方

1. スマホのブラウザで公開URLを開く
2. 共有メニューから「ホーム画面に追加」
3. 右下の「＋」から相手を登録

機種変更の際は、設定 → バックアップ「保存する」でJSONを保存し、新しい端末で「復元する」。

## 技術構成

- ビルドなしの静的Webアプリ(HTML / CSS / JavaScript)
- データ保存: localStorage
- PWA: Web App Manifest + Service Worker
- アバター・アイコン: Gemini API (`tools/gen_avatars.py`) で生成

## 開発

```
python -m http.server 5633 --directory .
```

でローカル起動。デプロイはmainブランチへのpushでGitHub Pagesに反映。
