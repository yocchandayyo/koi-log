# 恋ログ — マッチングアプリ相手管理PWA 設計書

日付: 2026-07-05
ステータス: 承認済み(案B: PWA + 端末内保存)

## 目的

マッチングアプリで出会った人たちの情報・進展・会話メモを一元管理するスマホ向けアプリ。
まずは本人が使い、最終的には一般公開(ローンチ)することを見据えたプロダクト品質で作る。

## 方針

- **形態**: PWA(ホーム画面に追加できるWebアプリ)。GitHub Pagesで公開
- **データ保存**: 端末内のみ(localStorage)。サーバーなし・アカウントなし。プライバシー面の売りにもなる
- **写真**: 実写ではなくAIイラストのアバターをGemini APIで事前生成し、アプリに同梱。ユーザーが選択する
- **言語**: 日本語UI
- **将来**: パフェゲームと同様にTWA化してPlayストア展開できる構成にする

## 機能

### 1. ホーム(一覧)画面
- 相手をカード表示: アバター、名前、年齢、出会ったアプリ、ステータスバッジ、好感度★、次の予定
- ステータスタブで絞り込み(すべて / マッチ中 / メッセージ中 / デート済み / 交際中 / 終了)
- 追加ボタン(+)から新規登録

### 2. ステータス管理
- ステージ: マッチ中 → メッセージ中 → デート済み → 交際中 / 終了
- 詳細画面からワンタップで変更

### 3. 詳細画面
- プロフィール: 名前、年齢、出会ったアプリ、職業、住まい、趣味、フリーメモ
- 好感度: ★1〜5
- 相性メモ: 合うところ / 合わないところ
- 次の予定: 日付+内容

### 4. タイムライン(詳細画面内)
- 会った日・話した内容を時系列で記録(種別: デート / 通話 / メッセージ / メモ)
- 「この話もうしたっけ?」防止が主目的

### 5. アバター
- Gemini(gemini-2.5-flash-image)で生成したイラスト16種程度から選択

### 6. 設定
- データのエクスポート / インポート(JSONファイル)— 機種変更対策
- 全データ削除

## 技術構成

- ビルドなしの静的構成: `index.html` + `css/` + `js/`(モジュール分割)
- データ: localStorage(キー `koilog-data`、バージョン付きJSON)
- PWA: `manifest.webmanifest` + `sw.js`(アプリシェルをキャッシュ、オフライン動作)
- デプロイ: GitHub リポジトリ `koi-log`、mainブランチ → GitHub Pages

## デザイン

- スマホファースト(〜430px基準)、単一ページでビュー切替
- 配色: コーラルピンク×クリーム系(恋愛アプリらしい温かみ。会社ブランドの水色とは別物として扱う)
- 丸ゴシック系フォント、角丸カード、ローンチに耐える仕上げ

## 対象外(今回はやらない)

- クラウド同期・アカウント機能
- 通知(リマインド)機能
- 実写写真のアップロード
